# THE RULE (Alex's standing decision for this material)
# ----------------------------------------------------
#   Links and timestamps only. No stills, no frame grabs, no clips, no thumbnails,
#   no re-hosting, no transcript excerpts pasted into a chapter.
#   The manual may cite a moment; it may not reproduce it.
#   This is stricter than the LDO image ruling in CONVENTIONS.md ("Image licensing")
#   because that ruling covers LDO's own documentation, not third-party video.
#   Only Alex can change this rule; until he does, a chapter link looks like:
#     Video: [Steve Builds, Part 4 — Z joints](https://www.youtube.com/watch?v=...&t=3352s)
#
# WHAT IS AND IS NOT STORED HERE
# ------------------------------
#   MANIFEST.md    generated  step -> video/timestamp table with confidence and
#                             divergence notes. Do not hand-edit; edit video_map.yml.
#   video_map.yml  hand-written  the mapping itself: one entry per video segment
#                             (video id, time range, manual chapter, step range) plus
#                             per-step caption keywords. This is the file to edit.
#   playlist.json  generated  raw yt-dlp metadata for the playlist and all 11 videos —
#                             title, duration, upload date, channel, description,
#                             YouTube chapter markers, licence, caption-track lists.
#                             Pruned of formats/thumbnails/heatmap/live-chat.
#   (not stored)   captions   ~4 MB of auto-generated English VTT, cached OUTSIDE the
#                             repo at ~/.cache/voron-video-map/. They are YouTube's
#                             machine transcription of someone else's speech; they are
#                             re-fetchable and are not committed.
#   (not stored)   video      nothing is ever downloaded. --skip-download is always set.
#
# TOOLING
# -------
# yt-dlp is deliberately NOT in requirements*.txt. Use a scratch venv:
#   uv venv /tmp/ytdl && uv pip install --python /tmp/ytdl/bin/python yt-dlp
#   python3 scripts/video_map.py --refresh --ytdlp /tmp/ytdl/bin/yt-dlp
#   python3 scripts/video_map.py            # regenerate MANIFEST.md only
# Fetched with yt-dlp 2026.08.19. YouTube rate-limits (HTTP 429) a full-playlist
# caption pull; re-running --refresh fills in whatever was skipped.
