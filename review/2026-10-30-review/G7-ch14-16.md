### G7-01 major goal 1 — 14.19 tells PrusaSlicer users to set top-layer line width "100 %", which PrusaSlicer computes over **layer height** (0.2 mm lines), so the EM test is invalid
- `14-calibration.md:834`: "Slice at top-layer line width 100 %, infill 30 %+, top solid infill speed ~60 mm/s, normal fan."
- `:861` (gate-calc `slice` row) repeats "top layer line width 100 %".
- **Source, PrusaSlicer 2.9.6:** `PrintConfig.cpp:3730-3736`, `top_infill_extrusion_width`: "If expressed as percentage (for example 90%) it will be computed over **layer height**." At 0.2 mm layers, 100 % is a 0.2 mm bead from a 0.4 mm nozzle, and the top surface it gives says nothing about flow.
- **Source, Ellis** (`extrusion_multiplier.md`, Print Settings): "Top Layer Line Width: 100% — ⚠ Remember, don't use these percentages in PS and Cura… you must instead put the actual number in millimeters (e.g. **0.4** with a 0.4mm nozzle)."
- 14.19 also omits three Ellis settings that change the reading:
  - **Bottom layers 2** with *minimum shell thickness* 0.
  - **Top layers ~10–11**.
  - **Minimum layer time 0.** The ASA filament presets slow down short layers, and a 30×30 mm layer is short, so top solid infill would print well under the 60 mm/s being tuned for.
- **Fix:**
  - `:834` → "Slice at top solid infill line width **0.40 mm** (type the number: PrusaSlicer reads a % as a share of layer height), infill 30 %+, bottom layers 2 with minimum shell thickness 0, top layers 10, top solid infill ~60 mm/s, *Slow down if layer print time is below* 0, normal fan."
  - Gate row `slice` label: the same text.

### G7-02 major goal 1+3 — 14.19's Tip ("right-click each object → add settings → Extrusion multiplier … on one plate") cannot be done in PrusaSlicer 2.9.6, and the chapter does not budget the eight separate prints that result

Slice one cube per value, or slice the cube once at 100 % and send `M221 S92` (S94, …) from the console before each run; `M221 S100` after. Run the four back-to-back while the chamber is hot."

  - Tap-tree `:311`: "Too early, or the probe grazes the plate: it is mounted too low, so raise it in the bracket. Too late: it is mounted too high, or there is tape on the sensing face; lower it so it triggers with the nozzle ~2 mm above the plate, tape front and sides only."

### G7-05 major goal 3 — Parts A, B, D and G heat the closed or open machine four times where one 1½–2 h soak gives every reading
**The current sequence:**

| Step | Machine state | What it does |
|---|---|---|
| 14.3 | Bed 100 °C, 10–20 min, door open | `G32`, `PROBE_ACCURACY`, heaters off |
| 14.4 | "Cold or cooling" | Re-tension A/B |
| 14.5 | Cold | Re-tension Z |
| 14.6 | Bed 110 °C, **1½–2 h closed soak** | `PROBE_ACCURACY`, QGL ×3–5, Z lock, QGL + `PROBE_ACCURACY` again, heaters off |
| 14.8 | Bed 110 °C, closed, **up to 45 min from cold** | Log the settled `chamber_temp` |
| 14.22 | "Fully heat-soaked and QGL'd" (a fourth soak) | `BED_MESH_CALIBRATE` for Variance |

**Why each extra heat is redundant:**
- 14.3's QGL is thrown away by 14.4/14.5, which re-tension all six belts.
- 14.3's checks (heaters ±0.5 °C, σ < 0.003) are repeated hot in 14.6 row 1 and row 4.
- 14.4 has to wait for 14.3's heat to dissipate.
- 14.8's conditions (bed 110, panels and door shut, from cold) are exactly the first 45 min of 14.6's soak. 14.6's own Check already requires "`chamber_temp` plateaued for at least 20 minutes".
- 14.22's mesh variance (Voron: "fully heat soak, run all homing/leveling, then BED_MESH_CALIBRATE") is available at the end of 14.6 row 4: hot, soaked, QGL'd and with the Z joints locked.

**Saving:** one ~45 min soak, one 10–20 min warm-up, one cool-down wait and ~25 min hands-on: well over 30 min.

**Fix (no renumbering):**
- **14.3:** becomes a cold check. Confirm `PROBE_ACCURACY` from Ch 13 is logged; "the hot check is row 1 of Step 14.6". Alternatively mark the step "skip if Ch 13's 13.32 passed within the session".
- **14.6 Do 2:** add "Log `chamber_temp` at 45 min and when it plateaus: that is Step 14.8's reading."
- **14.6 row 4:** add "then `BED_MESH_CALIBRATE` and note Variance (Step 14.22 reads it)".
- **14.8:** "Take the settled value 14.6 logged; re-soak only if you skipped 14.6's log."
- **14.22 Do 1:** "Use 14.6's mesh, or mesh again at the end of any hot print."
- Update the 14.3/14.8 Pause lines and `:12` Time.
- Confidence: high that the readings coincide; the order of 14.7 (rotation distance) is unaffected.
