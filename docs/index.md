# Voron 2.4 350 — Build Manual

This site consolidates the Voron 2.4 R2 Rev D+ 350 build into one Prusa-style manual: see the [Manual](manual/00-index.md) for step-by-step chapters, the [Print plan](voron-print-plan.md) for batch order and dependencies, and the [Instruction survey](voron-build-instructions-survey.md) for source docs and known deviations.

!!! tip "Bench mode"
    Open this on the iPad at `http://<hostname>.local:8000` (printed by `scripts/serve.sh`) while the Mac is on the LAN. Add the page to the Home Screen (Share → Add to Home Screen) for a full-screen, app-like view, and enable Guided Access or turn up Auto-Lock so the screen doesn't sleep mid-step.
