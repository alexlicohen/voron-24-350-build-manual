# Voron 2.4 350 — Build Manual

This site consolidates the Voron 2.4 R2 Rev D+ 350 build into one Prusa-style manual: see the [Manual](manual/00-index.md) for step-by-step chapters, the [Print plan](voron-print-plan.md) for batch order and dependencies, and the [Instruction survey](voron-build-instructions-survey.md) for source docs and known deviations.

!!! tip "Bench mode"
    Open <https://alexlicohen.github.io/voron-24-350-build-manual/> on the iPad (or the LAN URL printed by `scripts/serve.sh` when editing offline). Share → Add to Home Screen for a full-screen, app-like view. Tap the ☼ button in the header to keep the screen awake while you work — it re-arms automatically if the tab is backgrounded, though on iPadOS 16.4–18.3 it only holds inside Safari itself, not once added to the Home Screen (18.4+ fixes this); turn up Auto-Lock as a fallback on older iPadOS. Searching a bare step number (`10.58`) is faster than "Step 10.58". Every step gets a done checkbox that persists per-device in the browser, with a "Resume" pill that jumps to your first unchecked step and per-chapter N/M counts on the [Manual index](manual/00-index.md). Chapters with three or more sections get a sticky jump bar of section chips under the header so you can skip around without hunting the collapsed sidebar. [Tonight](manual/00-tonight.md) turns every chapter's `Time:` and `Pause:` lines into a 30/60/90-minute session planner, generated fresh on every build. Those same `Pause:` lines mark the stopping points in each chapter — where a sub-assembly is safe to leave and what not to do before walking away. Every step also ends with a `Source:` line pinning it to the exact manual page, LDO doc or print-plan section it came from, so you can compare notes with the original. The print section (see [print-ready checklists and bin labels](print/checklists.md)) has print-ready Checkpoint checklists and a bin-labels sheet — chapter number, printed-parts list, and a QR code back to the live chapter — for the garage bench where a tablet doesn't survive.

    To add a bench photo: shoot it on the iPad, let it land via iCloud Photos or AirDrop in the drop folder on the Mac (`~/Pictures/voron-drop` by default), name it (or a sidecar note) with the step id — `10.58-2.jpg` — and run `python3 scripts/ingest_photos.py`; it resizes, strips EXIF, and files the photo next to the CAD render in that step. Safe to re-run. `python3 scripts/photo_wanted.py` lists every step still missing one. See [Bench photos](manual/CONVENTIONS.md#bench-photos-added-2026-09-05-evening) for the full convention.
