# Bench photos

Alex's own photos of this build (not mirrored/licensed third-party material —
see `docs/manual/assets/remote/` and its `SOURCES.txt` files for that). Filed
by `scripts/ingest_photos.py`; see `docs/manual/CONVENTIONS.md` → "Bench
photos" for the workflow and naming convention. Don't hand-edit filenames —
the chapter markdown links them by exact path.

Layout: `<chapter-slug>/<step>-<n>.jpg` (e.g. `10-wiring/10.58-2.jpg`), plus
an optional `<chapter-slug>/captions.yml` mapping filename to a one-line
caption.

`WANTED.md` in this folder (when present) is generated by
`scripts/photo_wanted.py` — don't hand-edit it.
